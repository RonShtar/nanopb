## 1. Install

1. `python tools/wireshark/tests/live/live_test.py setup` (add `--reset-config` if you already configured the studio for your own protos).
2. Wireshark: **Analyze > Reload Lua Plugins** (Ctrl+Shift+L).
3. **Help > About Wireshark > Plugins** lists `nanopb_studio.lua` and `nanopb_any_dissector.lua` with no load errors.
4. **Edit > Preferences > Protocols > NANOPB** shows Port map = `udp:5000=demo.envelope.Envelope,tcp:7000=demo.telemetry.Telemetry`, "Treat unknown payload as Any" and "Detect Any on any port (heuristic)" both checked.
